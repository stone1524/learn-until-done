# learn-until-done

**给编码 agent 的学习教练 skill。** 把「我要学 X」变成一场判据先行、不弃坑的学习——每项可演示成果都真实通过之前，你和 AI 谁都不许宣布「学完了」。

learn-until-done 的方法论提炼自三项真实完成的学习实践（一份 10 周技术阅读路线、一份逐周学习排期、一份工具教程拆解），打包为单个可组合 skill。无框架、无依赖，就一个 agent 可加载的文件夹。英文说明见 [README.md](./README.md)。

## 为什么需要它

大多数学习计划死于同样的方式：

- **没有「学会」的定义**。「把课看完」不是判据——看完了、点头了，什么可演示的东西都没留下。
- **囤资源**。二十个标签页、三门课、没有主教材——于是什么都没读。
- **第三周崩盘**。第一次滑期引发连锁反应：计划没有砍单规则，错过一周悄悄变成错过一月。
- **无声弃坑**。没有反馈的动力持续衰减，等注意到时计划已经死了三周。

learn-until-done 把这些对策写成 agent 强制执行的**硬门禁**——不是建议。

## 工作方式

五个阶段，阶段之间有门禁，没有任何东西可以静默推进。

1. **启动澄清（阶段 0）**——先问清四件事：动机、**学会判据**（可演示成果清单+量化指标，在打开任何资料**之前**写好）、时间预算、硬截止。没判据，不开工。
2. **侦察与计划（阶段 1）**——集中侦察一次：选定**唯一主资料**，先跑通官方最小 demo 验证环境，然后产出单一入口 `PLAN.md`：周块、时间盒、最小成果（能打开/能跑通/能演示）、复盘栏，以及**开工前就写好的滑期砍单规则**。
3. **周循环带跑（阶段 2）**——每周唯一主线、时间盒推进，每项成果都要证据核验（命令输出/截图/录音）。滑期走预设砍单清单，绝不熬夜加码。只砍 nice-to-have；**里程碑只许顺延补完，不许取消**。
4. **验收（阶段 3）**——阶段 0 的判据逐项现场演示。未过项明确标「顺延补完」或「降范围交付」，绝不默默消失。
5. **沉淀（阶段 4）**——全部产物落进 `learning/<域名>/`：计划、笔记、成果物、一句话复盘。

## 核心规则

- **判据先于内容**。「看完了」不是标准。
- **主资料唯一**。路上发现的好东西进「待看区」，不进排期。
- **砍单规则在滑期之前写好**。没有它的计划过不了审。
- **里程碑只滑不砍**。允许顺延补完，不允许凭空消失。
- **断更两周触发协议，不是说教**。里程碑拆半、引入外部反馈——不靠加码自律。
- **三天速成绝不悄悄变成三月长征**。换档必须显式决策。

三档同一骨架：**A** 月级大路线 · **B** 周级系统学习（1–4 周）· **C** 几天速成。档位越小砍的是流程重量，判据与验收永不砍。

## 安装

适用于任何加载 Agent Skills（`SKILL.md` 文件夹）的 agent——Claude Code、ZCode、Codex、Cursor 及兼容 harness。

```bash
git clone https://github.com/stone1524/learn-until-done.git
# Claude Code
cp -r learn-until-done/learn-until-done ~/.claude/skills/
# 其他 agent：拷进你的 skills 目录，如 ~/.agents/skills/
```

无需 slash 命令。说「我要学 X」「帮我规划学 X」「X 速成」即自动触发；单概念答疑、读代码库、开发任务明确不接管（description 内有 NOT-for 划界）。
