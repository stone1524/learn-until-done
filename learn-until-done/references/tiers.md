# 三档裁剪矩阵

档位在 SKILL.md 判定。本表回答「这一段在每一档做到什么程度」。原则：档位越小砍流程，**不砍判据、不砍验收**——砍掉的只是编排重量。

| 流水线段 | A 月级大路线 | B 周级系统学习 | C 几天速成 |
|---|---|---|---|
| 阶段 0 启动澄清 | 四要素全做；动机深挖一层（求职→判据要对齐岗位要求；作品→判据要对齐可展示形态） | 四要素全做，一轮问完 | 只问判据+截止两项；时间预算按天估 |
| 阶段 1 侦察与计划 | 资源侦察做足（主资料唯一+辅助清单+待看区）；先跑通官方 demo；PLAN.md 全格式：逐周块+按月粗排+外部节点（投递/发布等硬日期） | 同左但无月粗排、无外部节点；PLAN.md 只排逐周块 | 资源速选：1 个主资料+1 个备胎；demo 照跑；计划缩为半页：判据+截止+单次产出物 |
| 阶段 2 带跑 | 周循环全做：唯一主线+时间盒+最小成果+日志+复盘栏；用户另有长期项目/素材线时，各占固定时间盒从主线扣减，不额外加时 | 周循环做，但日志降为每学习日 3–5 行 | 无周循环：单次冲刺（检查点与到期处理见「带跑行为规则」） |
| 阶段 3 验收 | 成果清单逐项演示+量化指标+各里程碑对账 | 成果清单逐项演示+量化指标 | 单次产出能跑通即过 |
| 阶段 4 沉淀 | 完整归档+复盘+简历素材（可选） | 归档+一句复盘 | 归档+一句复盘 |

## 砍单规则按档裁剪

- **A 档**：完整砍单顺序（先砍 nice-to-have 清单→永不砍里程碑检验项）+ 顺延分档（可顺延/绝不顺延两列）+ 断更信号协议（见「带跑行为规则」）。
- **B 档**：砍单规则简化为两档（可砍/不可砍），断更信号保留。
- **C 档**：无砍单——到期处理见「带跑行为规则」。

## 判档争议时

- 用户说「系统学/路线」→ 偏 A/B；说「入门」看体量归 B 或 C；说「速成/上手就行/够用就好」→ C 档。
- 用户只给「我想学 X」没给体量 → 按四要素里的时间预算反推：≥4 周→A，1–4 周→B，<1 周→C；仍不明就直接问。
- 中途扩档/降档必须用户明示，AI 不得自行升级（见 SKILL.md 红旗表）。
