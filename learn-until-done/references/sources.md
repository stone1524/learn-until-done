# 来源与维护义务

> 学习方法论提炼自作者三项已验证的真实学习实践（一份 10 周技术阅读路线、一份逐周求职学习排期、一份工具教程拆解笔记），无外部方法论移植；AI 交互纪律为设计决策。

## 方法论来源（按贡献映射）

| 来源（脱敏描述） | 贡献 |
|---|---|
| 技术阅读路线（10 周计划：单一入口文件 + 每周固定节奏） | 单一入口文件原则（「只盯这一个文件」）；只读排期内材料 + 待看区；赶时间减法规则；卡点 30 分钟问 AI 要「讲解+选项」不代写；卡点逃生口三类；口述讲清式验收（降为可选项） |
| 逐周学习排期（含里程碑与滑期处理） | 周块/时间盒/最小成果三件套；「能打开/能演示/能跑通」验收口径；复盘栏三问；砍单规则（先砍 nice-to-have、永不砍里程碑检验项、允许跨周补完不允许取消验收、不熬夜补课）；断更两周=动力风险信号→里程碑拆半+外部反馈；外部截止驱动完成率；量化指标（日志覆盖率等） |
| 工具教程拆解笔记（程序化动画工作流） | 给参考先复刻再改；范围蔓延警告（「纯粹追求好看没有尽头」）；环境一次搭好长期用（统一依赖管理+练习独立子目录）；工作流稳定前不折腾工具 |

## 设计决策记录

- 场景=学新技术领域；交互=先产计划+教练式分阶段带跑；三档规模（A 月级 / B 周级 / C 几天速成）分档裁剪
- 判据默认=可演示成果清单+量化进度指标；口述验收与简历素材转化仅可选项
- 反弃坑=硬性门禁；AI 自动触发；不接管已有计划；落盘=每领域一目录 `learning/<域名>/`
- AI 交互纪律（设计决策）：无提问通道时待确认项落盘并停在当前段等确认；扩档/降档需用户明示；验收出路含「降范围交付」
- v0.2.0 结构与 token 优化：主文 65→62 行、C 档到期行为归一到「带跑行为规则」一处；语义无损经独立复审全量比对
- v0.3.0 公开发布：更名 learn-until-done；描述与来源文件脱敏（去除个人路径与在途计划引用）；双语 README

## 维护义务

1. 新方法/新教训 → 更新对应 reference 并在来源表登记，version +0.0.1。
2. 方法论原则变化 → 全量重蒸馏本 skill 全部五个文件，并更新上方决策记录。
3. 触发描述改动后必须重跑触发测试（正例+负例），结果记入当次交付说明。
