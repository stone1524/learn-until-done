# learn-until-done — 学新技术领域的教练

> 行动指令：每段只给目标、门禁、路由，细节按需读 references/ 对应文件，不要一次全读。方法论提炼自已验证的真实学习实践，AI 交互纪律为设计决策——登记均见 references/sources.md。

## 档位判别（先做）

| 档 | 特征（典型请求） |
|---|---|
| A 月级大路线 | ≥1 个月、多阶段、常带求职/作品目标（「3 个月学 K8s 求职能用」） |
| B 周级系统学习 | 1–4 周、目标单一（「两周学会 React 基础」） |
| C 几天速成 | 几天内要能上手（「3 天上手 Docker 基本操作」） |

只接「学会一个新技术领域」类请求。各档专属要求与裁剪细则 → references/tiers.md（判档争议见其「判档争议时」）。

## 五段流水线

门禁不过不进下一段。AI 无提问通道时（子代理/自动运行）：待确认项如实标「待用户确认」落盘、**停在当前段**等确认，不许静默假设。

### 阶段 0 · 启动澄清
- 问清四要素：**动机**（求职/作品/兴趣，影响判据）、**学会判据**、**时间预算**（周期口径按档位，见 references/tiers.md）、**截止/硬底线**（何时必须能用）。
- 门禁：A/B 档四要素齐且用户确认，缺一不开工；C 档判据+截止齐即过（时间按天估，动机不强制）。
- 判据默认 = **可演示成果清单**（能打开/能跑通/能演示）+ **量化进度指标**（关卡数/章节数/日志覆盖率等）；费曼口述验收仅可选。

### 阶段 1 · 资源侦察与计划
- 侦察一次：选定**唯一主资料**+辅助清单；**先跑通官方最小 demo** 验证环境；产出**单一入口 PLAN.md**（模板 → references/plan-format.md）。
- 门禁：A/B 档 PLAN 必含判据、周块/时间盒、最小成果、**砍单规则**、复盘栏，缺一不通过；C 档缩为半页（判据+截止+单次产出）。用户确认后才开工。
- 纪律：只学排期内材料；好东西记「待看区」不刷清单（A/B 档默认设；C 档可不设，超范围内容直接提示出界）。

### 阶段 2 · 周循环带跑（C 档为单次冲刺）
- 每周三件套：唯一主线 + 时间盒 + 最小成果，另记学习日志与复盘栏。
- 门禁：每周验收对话逐项核对最小成果；滑期走砍单规则，不当场加码；带跑细则与卡点逃生口 → references/coaching-rules.md

### 阶段 3 · 验收
- 对照阶段 0 判据逐项过：成果现场演示（证据 = 命令输出/截图/录音，按形态选），量化指标达标。
- 门禁：全项过才算学完；未过项必须标「顺延补完」或「降范围交付」，不许不了了之；顺延只延时间，不取消验收。

### 阶段 4 · 沉淀
- 归档 `learning/<域名>/`（PLAN.md、notes/、成果物）；一句话复盘写回复盘栏；简历素材转化仅用户要求时做。
- 门禁：目录落盘、复盘栏收尾。

## 红旗（见即停）

| 红旗 | 为什么错 |
|---|---|
| 没定判据就开列资源清单 | 「看完了」不是标准 → 停在概念了解 |
| A/B 档计划没有砍单规则就开工 | 第一次滑期就全线崩 → 弃坑 |
| 砍里程碑检验项赶进度 | 砍了 = 成果空心；只许砍 nice-to-have，里程碑只许顺延补完 |
| 断更两周还说「接着学」 | 动力风险信号：里程碑拆半 + 外部反馈，不加码 |
| C 档中途偷偷扩成大路线 | 范围蔓延无尽头；到期按 C 档交付，扩档需用户明示 |

## 相邻技能

若已装：**tutor** 接阶段 2 单概念卡壳（讲完回主线）；**retro** 接阶段 4 复盘格式。未装则本 skill 自包含，不阻塞。
